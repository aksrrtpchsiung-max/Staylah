## Reproducible Execution

Normal regression (when no database is provided, the 9 PostgreSQL tests are explicitly skipped):

```bash
.venv/bin/python -m unittest discover -s tests -q
for script in web/public/*.js web/public/js/*.js; do node --check "$script"; done
```

Database tests use a separate test instance and do not point to the daily database. This time, a temporary instance under `/private/tmp/` was used
PostgreSQL, port 55438. Set the following variables to your own isolated instance and then initialize:

```bash
export TEST_DATABASE_URL='postgresql+psycopg://refactor@127.0.0.1:55438/postgres'
DATABASE_URL="$TEST_DATABASE_URL" LANGGRAPH_CHECKPOINT_DB_URI="$TEST_DATABASE_URL" \
  .venv/bin/python scripts/init_postgres.py
.venv/bin/python -m unittest discover -s tests -q
```

Export the original version in a new directory (the directory name must be unused), then retest cross-version recovery; use a new prefix each time:

```bash
mkdir /tmp/property-agent-original
git archive 41f86d9 | tar -x -C /tmp/property-agent-original
.venv/bin/python scripts/verify_checkpoint_compatibility.py create \
  --source-root /tmp/property-agent-original --prefix checkpoint-check-1
.venv/bin/python scripts/verify_checkpoint_compatibility.py resume --prefix checkpoint-check-1
```

For reverse verification, create with the current version, then resume with the original version via `--source-root`.
